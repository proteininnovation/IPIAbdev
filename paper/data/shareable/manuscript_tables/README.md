# Public DELPHI manuscript tables

This directory contains the named manuscript tables approved for public code
and data release.

- Supplementary Tables 2, 4, 5, and 7 are exact copies of the final submission
  files.
- Supplementary Table 4 contains an IPI validation worksheet without sequence
  fields and a DS1 worksheet with public DS1 sequences and prediction results.
- Supplementary Table 5 contains public Jain2017, GDPa1, and GDPa3 sequences,
  assays, and DELPHI prediction results.
- Extended Data Tables 1-3 contain aggregate PSR, cross-dataset, and SEC model
  performance results and were already sequence-free.

No private IPI antibody sequences are included. Public DS1/Jain2017/GDPa
sequences remain part of the official supplementary data. `manifest.json`
records sources, worksheet dimensions, hashes, exact-copy status, and the IPI
sequence audit.

The public Table 4 supports regeneration of Extended Data Figures 3 and 5.
